# Ultrasound Signal and Image Processing

A curriculum in the making. It is planned to take a learner from engineering
fundamentals to the level expected of a PhD researcher or an industry engineer
in medical ultrasound, along the full chain from mathematics and physics
through transducers, hardware, beamforming, image formation and image
processing to product practice and interview preparation. The plan has 100
modules in 13 parts, grouped into five courses.

[CURRICULUM.md](CURRICULUM.md) is the master plan. It defines the scope, the
module list, the course projects, the assessment types, and the tools, datasets
and references the modules draw on.

## Status

The curriculum is written one module at a time, starting with the
fundamentals, in the order given in section 14 of the plan.
[ROADMAP.md](ROADMAP.md) tracks what is finished and what comes next. No
module is published yet.

## How a module is organised

Every technical module has the same six elements: concept, derivation,
implementation, coding exercise, reading and interview questions. Lessons are
Markdown files, and each coding exercise has a tested reference
implementation in Python and in MATLAB. A Jupyter notebook reproduces the
numerical results of each module and exports its figures.

- [docs/module-template.md](docs/module-template.md): the files that make up a
  module and what each one contains.
- [docs/conventions.md](docs/conventions.md): notation, units, array layouts
  and code style shared by all modules.
